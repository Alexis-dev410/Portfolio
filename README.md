# Godot Game Portfolio

This folder is a Godot 4 portfolio project containing three original game prototypes created over the course of a semester. The project acts as a central showcase menu, where each game can be launched from the main portfolio screen.

## Project Overview

This repository is a collection of short game projects, each representing a different assignment and gameplay style:

- Parkour game: "Help Brian Get Home"
- Prison escape game: "Prison Escape"
- Tower defense game: "Tower Defense"


## Folder Structure

- `Assets/` - Visual art and audio used by the portfolio and the game menu.
- `Games/` - Exported Windows executables for the three completed games.
- `Scenes/` - Godot scene files, including the main portfolio scene (`Portfolio.tscn`).
- `Scripts/` - Game logic for launching each game from the menu (`portfolio.gd`).
- `Documents/` - Related notes and project documentation.
- `project.godot` - Main Godot project configuration file.

## Included Games

### 1. Parkour Game
A fast-paced movement-focused game where the player helps Brian navigate a series of parkour challenges and reach safety.

### 2. Prison Escape
A stealth and survival-style game where the player avoids guards and escapes from prison.

### 3. Tower Defense
A defense game where the player fights off waves of enemies and aims for a high score.

## How to Run

1. Open this folder in Godot 4.
2. Open the project file: `project.godot`.
3. Press Play to run the portfolio screen.
4. Select the game you want to play from the main menu.

You can also launch the exported builds directly from the `Games/` folder if you want to play the packaged executables without opening Godot.
